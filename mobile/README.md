# 手机安装与安卓构建

安卓使用内置网页资源的 Capacitor App；苹果按当前选择使用 Safari 桌面安装版。

手机安装入口：https://jiaban-x2m.pages.dev/install.html

## 使用

- 安卓下载安装入口里的 APK。最低 Android 7.0。首次安装可能需要允许当前浏览器安装应用。
- 苹果用 Safari 打开正式网站，分享 → 添加到主屏幕，有「作为网页 App 打开」选项时开启。
- App 与网页本机存储相互独立。先在原设备复制同步码，再到 App 设置连接同一个空间；首次安装不要新建另一个空间来找旧数据。
- 安卓页面随安装包提供，首次打开即使没有网络也可记账；保存后联网同步到原 Cloudflare 服务。
- JSON/CSV 导出会打开系统分享面板，可保存或交给文件管理应用。导入使用系统文件选择器。
- 安卓实体返回键先关闭编辑面板，再返回记录页，最后退出；未保存内容仍会提示。
- 安卓 1.3.0 起，打开或返回 App 时检查更新，设置中也可手动检查。在 App 内下载后由系统确认安装；首次需允许「加班记录」安装应用。旧版先覆盖安装一次 1.3.0，之后无需去网站查找安装包。请勿先卸载旧版。

## 构建

已有 Android Studio 环境可打开 `mobile/android`，使用 JDK 21、Android SDK 36。

本项目也提供 Windows 本地工具链脚本，依赖下载到根目录 `.local`，不修改系统 PATH：

```powershell
cd mobile
pnpm install --frozen-lockfile
python make-icons.py
python bootstrap-android.py
python build-android.py
```

构建脚本会准备网页资源、同步原生插件、编译发布包、执行 Android lint 并验证 APK 签名，输出到 `dist/mobile/jiaban-1.3.1.apk`。Python 图标脚本需要 Pillow。也可以在根目录先运行 `python sync_public.py` 发布网页版。

**后续升级必须保留原来的应用 ID 和签名密钥**：签名材料位于根目录 `.local/android-signing/`，本机 Gradle 配置 `mobile/android/signing.properties` 也含密码。这些文件已经忽略，不得放入网页、APK 附件或源代码分享包。请由项目所有者另存到自己的安全备份位置。不要丢失密钥后用新密钥发布同包名升级。

版本名在 `mobile/package.json` 与 `mobile/android/app/build.gradle`，升级时增加 `versionCode`，同步修改 `加班记录.html` 底部 `appVersionLabel` 的版本号并更新安装页链接；构建与发布脚本会核对这些版本，防止网页、手机和更新清单不一致。

## 实现边界

- `mobile/prepare.mjs` 只复制页面、图标和客户端脚本，禁止把 `.cf_env`、Worker、数据库或开发目录装进 APK。
- `runtime.js` 将同步请求固定发往正式网站 HTTPS 接口，使用原生 HTTP，继续使用原同步码；没有放宽服务端跨域限制。
- 原生备份只写入 App 自己的临时导出目录；没有照片、通讯录或公共存储权限。
- 发布包关闭网页调试和 Android 自动备份；应用内多设备同步和手工备份仍可用。
- 苹果当前交付桌面安装版，不包含可签名分发的 IPA；未来原生 iOS 版本需 Mac、Xcode 和 Apple 签名。

## 1.3.0 应用内更新

- 自动检查离线失败时安静跳过；同一版本选择稍后，一天内不再自动弹出。设置里的检查按钮不受此限制。
- 下载在 App 私有缓存中完成，显示进度；后台下载结束不会擅自弹出安装窗口。
- 下载只连接固定正式站，禁止重定向，并核对大小、SHA-256、包名、递增版本号和原签名。安卓系统仍要求用户确认覆盖安装。
- 安装前提醒未保存内容；原有本机数据与同步空间不变。苹果桌面版在新版缓存就绪后提示刷新，不强制重载草稿。
- 发新版：增加 package/Gradle 版本（versionCode 必须递增），修改 `mobile/release-notes.txt` 和安装页，运行 `mobile/build-android.py`，再运行根目录 `android_release.py` 将已签名 APK 与自动生成的 `downloads/android-latest.json` 一起放入 public。最后只用根目录 `cf_deploy.py` 发布。
- 已公开的版本文件不可覆盖。更新清单禁止缓存，发布脚本校验它与安装包、版本配置完全一致；发布后也核对正式清单。

## 1.3.1 同步设置界面

- 与网页一致：多设备同步默认折叠，点击标题展开或收起；收起时显示简短同步状态，后台自动同步继续运行。
- 安卓 1.3.0 可在应用内检查到 1.3.1；更早版本需先覆盖安装新版。应用 ID 和签名保持一致。

- 设置页底部显示当前版本；安卓读取本机已安装版本，网页显示本次发布版本。发布前校验可见版本号与安卓版本配置一致，避免提示版本和安装版本混淆。
